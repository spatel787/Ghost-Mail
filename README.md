# Ghost-Mail

Ghost-Mail is a senior design project focused on building a secure email encryption service that protects sensitive messages and attachments.

## Tech Stack

- .NET 10
- Node.js 22
- npm
- Docker
- Git

## Project Setup

Make sure you have the required tools installed before getting started.

Check your installed versions:

```bash
dotnet --version
node --version
npm --version
git --version
docker --version
```

## Run the frontend

Start the Vite development server from the `frontend` directory:

```bash
cd frontend
npm install
npm run dev
```

Open the URL printed by Vite (normally `http://localhost:5173`). In a remote
workspace or container, forward port `5173` in your editor if prompted.
