# Ghost-Mail

Ghost-Mail is a senior design project focused on building a secure email encryption service that protects sensitive messages and attachments.

## Tech Stack

- .NET 10
- Node.js 22
- npm
- Docker
- Git

## Project Setup

Make sure you have the required tools installed before getting started.

Check your installed versions:

```bash
dotnet --version
node --version
npm --version
git --version
docker --version
```
